# IONIC
Ion-Only Numerical Intercalation Code

This software is designed to model internal grain structures using a lattice Boltzmann method for ion transport
in and outside the grain. Currently, electrons are instantaneously transported to the surface of the grains and do not move.
The electric potential is obtained by solving the Poisson equation via a sparse matrix method utilising Scipy's stabilised biconjugate gradient function.
